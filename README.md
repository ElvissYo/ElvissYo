## What I've Been Building

**TrashCast** — Waste volume prediction system for Bandung, built for the AI Open Innovation Challenge 2026. Proposed stack: LightGBM + TFT ensemble, FastAPI, Streamlit, and OR-Tools for routing optimization.

**WINTEQ** — Predictive maintenance system for induction motors, developed in connection with Astra Otoparts. Core ML architecture is a CNN-LSTM with Attention for RUL estimation and anomaly detection, with an ASP.NET application layer.

**RetailPilot** — AI-powered retail management system with a normalized five-table PostgreSQL schema, built on React, Vite, Tailwind, and Supabase.

Other explorations include a Home Credit Indonesia credit default prediction project (CatBoost, LightGBM across 8 relational tables), an IHSG forecasting dashboard, and a FIFA World Cup match prediction model using CNN-LSTM and ELO-based features.
